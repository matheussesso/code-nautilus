# code-nautilus

This extension adds shortcuts to open files and folders in **VS Code**, **Antigravity IDE**, and **Cursor** from the Nautilus (Ubuntu Files) context menu.

During the installation process, you can choose which of these editors you want to enable.

## Installation

Run the following command to install the extension and configure your preferred editors:

```bash
wget -qO- https://raw.githubusercontent.com/matheussesso/code-nautilus/master/install.sh | bash
```

## Uninstallation

To remove the extension, run:

```bash
rm -f ~/.local/share/nautilus-python/extensions/code-nautilus.py
```
